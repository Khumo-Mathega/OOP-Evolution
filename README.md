# OOP-Evolution

## Brief Description

OOP-Evolution is a Java-based project that demonstrates and applies Object-Oriented Programming concepts.
This project is continuously improved by myself as I learn new OOP concepts

## Features

* Classes and Objects
* Interfaces
* Serialization & Deserialization
* File Handling

## Purpose

This project serves as a long-term learning system to practice and master Java OOP and backend development concepts.
